🎭 クリックジャッキング 攻撃デモ

攻撃者の偽ページ上に、被害者サイト（プロフィール）の iframe を透明に重ねてクリックを盗む

🖥 攻撃ステージ

① 同じブラウザで確認する場合: 「攻撃ステージを開く」で別ウィンドウを開き、スライダーで位置を調整します。
② 別ブラウザ（EdgeとChromeなど）でデモする場合: スライダーで位置を調整 → 「被害者用URLをコピー」→ 別ブラウザで貼り付け。

⚠ ステルスモード: 被害者にはデコイだけが見えています。「当選を確認する」クリック → 実際には削除ボタンが押されます。

🔗 被害者用URL（クロスブラウザ対応）

スライダーで位置を調整後、このURLをコピーして被害者に送る（または別ブラウザで開く）。
URLにX/Yオフセットが埋め込まれているため、別ブラウザで開いても位置が再現されます。

🎛 iframe 位置・透明度調整

← ステルス (被害者に見えない) (透けて見える) 半透明 →
マイナス → iframe を上にずらす（削除ボタンをデコイボタンの位置に合わせる）
マイナス → iframe を左に / プラス → 右にずらす

⚙ 攻撃の仕組み

  1. 攻撃者は自分のサイト（デコイ）に、被害者サイトを iframe で埋め込む（ほぼ透明）
  2. iframe は z-index が高く設定されており、クリックは iframe が受け取る
  3. 被害者には偽ページだけが見えており、「当選確認ボタン」をクリックしたつもりが…
  4. 実際には透明な iframe 内の「アカウントを削除する」ボタンが押される
  5. 対策: X-Frame-Options: DENY で iframe への埋め込み自体をブロック
💡 対策設定 で X-Frame-Options を ON にすると iframe が読み込まれなくなり、攻撃が無効化されます。
攻撃後は プロフィールページ でアカウントが削除されたか確認、 リセット で復元できます。

※ 攻撃ステージウィンドウとはブラウザの postMessage API で通信しています。
※ 攻撃ステージを閉じた後は「攻撃ステージを開く」ボタンで再度開いてください。
